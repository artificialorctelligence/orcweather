# Research written for Orclab

Four background skills in orclab's `stack-*` shape (`user-invocable: false`, every claim stamped
"confirmed live", Sources at the end). Copy each directory into orclab's `skills/` as-is.
Written 2026-09-14 for orcweather; the first real use of each corrects it.

| Skill | Answers |
|---|---|
| `source-librewxr/` | What LibreWXR serves (radar, nowcast, satellite, alerts, storm cells) and does not (point weather: wind, temperature, forecasts); public-instance terms; self-host sizing; tile URL shapes; companion point-data sources |
| `map-openstreetmap/` | OSM tile policy and what it forbids in a shipped app; `flutter_map` (six platforms) vs `maplibre_gl` (three); swappable base layer; overlay stacking |
| `car-android-auto/` | Car App Library weather category, manifest, `MapWithContentTemplate`, WE-1…WE-5 quality rules, the VirtualDisplay/Presentation path for a Flutter map |
| `car-carplay/` | Weather is not a CarPlay category; only navigation apps draw the map; the iOS 26 widget / Live Activity path that needs no entitlement |
